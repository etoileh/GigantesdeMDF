# GigantesdeMDF
## [![Info](https://img.icons8.com/?size=100&id=GkTOz4gayYVQ&format=png&color=000000)]Sobre o projeto
O projeto The Last Is The First foi desenvolvido como parte da disciplina de Programação de Hardware, com o objetivo de aplicar na prática os conhecimentos adquiridos durante o semestre, especialmente na programação de microcontroladores, no controle de componentes eletrônicos e na integração entre software e hardware.

A proposta consiste no desenvolvimento de um robô móvel controlado por meio de botões, permitindo realizar movimentos para frente, para trás, para a esquerda e para a direita, além de interromper o movimento quando os botões deixam de ser pressionados.
